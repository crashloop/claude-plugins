# Hoolint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code plugin whose Stop hook runs a uv/Python CLI that checks files the model touched, using stacked strategies (regex → semantic → local_llm → escalate) with committed waivers and a stand-down loop guard.

**Architecture:** Thin bash/python hook scripts feed a `hoolint` CLI living in `hoolint/app/` (uv project). The CLI detects changed files (session journal or git diff), runs rules whose stages filter a candidate set from cheap to expensive, and reports findings with exit codes the hook layer translates into block/allow.

**Tech Stack:** Python ≥3.13 (pathlib `full_match`), uv, model2vec, httpx, google-re2 (linear-time matching), tomli-w (write TOML; read uses stdlib tomllib), pytest.

## Executing this plan

- Work tasks in order. Each task's `Interfaces` block is the contract with its
  neighbours: it names every signature a later task consumes, so a fresh agent
  needs only its own task plus this header.
- A task is done when its stated check passes, not when its code is written.
  Run the command shown and compare against the stated expected output.
- Later tasks amend earlier files by design (Task 8 and Task 11 both extend
  `cli.py`). Where a task says "add" or "replace", keep everything else intact.
- `hoolint/README.md` and `hoolint/CONTEXT.md` already exist. `CONTEXT.md` is the
  glossary — use its terms (Rule, Stage, Strategy, Finding, Fingerprint, Waiver,
  Escalation, Stand-down) in code and docstrings; do not turn it into a spec.
- No `hoolint/.claude-plugin/plugin.json` is created: `hooks/hooks.json` is
  auto-discovered and the name derives from the directory. This diverges from the
  sibling `creed` plugin, which has one — a deliberate choice, not an omission.
- The repo's own standards apply to the code you write here (KISS/YAGNI, Google
  docstrings, 100-col lines, tests before implementation).

## Global Constraints

- Do NOT commit anything under `docs/superpowers/` (user decision). Commit code/task files only.
- Severity values: exactly `block` | `warn`.
- Fingerprint = `rule_id:file_path:sha256(span_text)[:16]`.
- Waivers file: `hoolint-waivers.toml` at project root, committed. Each entry carries
  `fingerprint`, `rule_id`, `file`, `lines`, a short `span` excerpt, and a mandatory `reason` —
  the excerpt is what makes the git-review gate reviewable.
- `hoolint waive` rejects any fingerprint absent from the last check's finding set
  (persisted in `.hoolint/state.json`). Waiving is strictly reactive to a real finding.
- Ephemeral state in `.hoolint/` (self-gitignored via `.hoolint/.gitignore` containing `*`).
- `stand_down_after` default 2, configurable in `[settings]`. Two counters use it: one keyed on
  the fingerprint set (same problem, no progress) and one unconditional (bounds churn).
- `local_llm` default `base_url`: `http://localhost:11434/v1`. Every call validates the resolved
  host and refuses anything outside loopback / RFC1918 — never a cloud provider, enforced not
  merely intended.
- All rule patterns run on `google-re2`, so no project-supplied pattern can hang the check.
  RE2 has no backreferences or lookaround; stock patterns are written accordingly.
- Semantic checks must never hit the network at check time: load models with `HF_HUB_OFFLINE=1`; only `hoolint warmup` downloads.
- Degrade loudly and safely: an unavailable strategy skips with a visible note, and because a
  skipped *filter* stage cannot have removed false positives, that rule's survivors are demoted
  to `warn` for the run. An incompletely-configured install reports but never blocks.
- Any unexpected exception inside a rule degrades that rule to a visible note; one bad rule
  never kills the whole check.
- Session-mode exit codes: 2 = block, 0 otherwise. Git-mode: 1 = block findings exist, 0 otherwise.
  `escalate` in git mode keeps severity and marks findings `not-judged`, so CI still fails on
  unjudged block-rule findings.
- Non-blocking session output (warn findings, stand-down handoff, trust notice) goes out as a
  `systemMessage` in the Stop hook's JSON response — bare stdout is discarded by the harness.
  Blocking feedback stays on stderr with exit 2.
- Max line length 100; Google-style docstrings on public functions.

```python
"""Finding: one rule violation anchored to a span in a file."""
import hashlib
from dataclasses import dataclass, field


@dataclass
class Finding:
    rule_id: str
    file: str
    start_line: int
    end_line: int
    span_text: str
    message: str
    severity: str = "warn"
    needs_judgment: bool = False
    judgment_prompt: str = ""
    notes: list[str] = field(default_factory=list)

    @property
    def fingerprint(self) -> str:
        """Stable identity: changes iff the offending span changes."""
        span_hash = hashlib.sha256(self.span_text.encode()).hexdigest()[:16]
        return f"{self.rule_id}:{self.file}:{span_hash}"

    def record(self) -> dict:
        """Minimal JSON-safe form, enough to write a reviewable waiver later."""
        return {"fingerprint": self.fingerprint, "rule_id": self.rule_id,
                "file": self.file, "start_line": self.start_line,
                "end_line": self.end_line, "span_text": self.span_text,
                "message": self.message}

    @classmethod
    def from_record(cls, rec: dict) -> "Finding":
        return cls(rule_id=rec["rule_id"], file=rec["file"],
                   start_line=rec["start_line"], end_line=rec["end_line"],
                   span_text=rec["span_text"], message=rec["message"])
```

```python
"""Load packaged defaults and merge the project's hoolint.toml per rule id."""
import tomllib
from dataclasses import dataclass
from importlib import resources
from pathlib import Path


@dataclass
class Config:
    rules: list[dict]
    settings: dict


def load_config(project_root: Path, extra_rules: list[dict] | None = None) -> Config:
    """Merge defaults <- project hoolint.toml <- extra_rules, per rule id.

    Args:
        project_root: Directory containing an optional hoolint.toml.
        extra_rules: Custom rules (from hoolint_rules/) merged last.
    """
    base = tomllib.loads(
        (resources.files("hoolint") / "defaults.toml").read_text())
    proj_file = project_root / "hoolint.toml"
    proj = tomllib.loads(proj_file.read_text()) if proj_file.exists() else {}
    rules = {r["id"]: r for r in base.get("rule", [])}
    for r in [*proj.get("rule", []), *(extra_rules or [])]:
        rules[r["id"]] = r  # wholesale override or add
    rules = {rid: r for rid, r in rules.items() if r.get("enabled", True)}
    settings = {**base.get("settings", {}), **proj.get("settings", {})}
    return Config(rules=list(rules.values()), settings=settings)
```

```python
"""Per-session record of files the model touched since the last check."""
import json
from pathlib import Path


def _path(root: Path, session_id: str) -> Path:
    return root / ".hoolint" / f"session-{session_id}.jsonl"


def add(root: Path, session_id: str, file_path: str) -> None:
    p = _path(root, session_id)
    p.parent.mkdir(exist_ok=True)
    gitignore = p.parent / ".gitignore"
    if not gitignore.exists():
        gitignore.write_text("*\n")
    with p.open("a") as f:
        f.write(json.dumps({"file": file_path}) + "\n")


def files(root: Path, session_id: str) -> list[Path]:
    """Journalled files that still exist and live inside the project root."""
    p = _path(root, session_id)
    if not p.exists():
        return []
    seen: dict[str, None] = {}
    for line in p.read_text().splitlines():
        seen.setdefault(json.loads(line)["file"])
    return [f for f in map(Path, seen)
            if f.exists() and f.is_relative_to(root)]


def clear(root: Path, session_id: str) -> None:
    _path(root, session_id).unlink(missing_ok=True)
```

```python
"""Git-mode change detection for verification pipelines."""
import subprocess
from pathlib import Path


def _run(root: Path, *args: str) -> subprocess.CompletedProcess:
    return subprocess.run(["git", *args], cwd=root, capture_output=True,
                          text=True, timeout=30)


def git_changed(root: Path, ref: str = "auto") -> list[Path]:
    """Files changed vs ref, plus untracked, restricted to inside root.

    ref='auto' resolves the merge-base with main, then master, else HEAD.
    """
    if ref == "auto":
        ref = "HEAD"
        for base in ("main", "master"):
            r = _run(root, "merge-base", "HEAD", base)
            if r.returncode == 0:
                ref = r.stdout.strip()
                break
    diff = _run(root, "diff", "--name-only", ref).stdout.splitlines()
    untracked = _run(root, "ls-files", "--others",
                     "--exclude-standard").stdout.splitlines()
    out: dict[Path, None] = {}
    for name in [*diff, *untracked]:
        p = (root / name).resolve()
        if p.exists() and p.is_relative_to(root.resolve()):
            out.setdefault(p)
    return list(out)
```

- Strategy protocol: `run(candidates: list[Finding] | None, stage: dict, ctx: Context) -> list[Finding]` — `None` candidates = generate from file; a list = filter/annotate it. Stage key `exclude` (list of patterns) drops matching spans. `STRATEGIES: dict[str, Strategy]` registry. `engine.run(cfg: Config, files: list[Path], root: Path, mode: str) -> list[Finding]`; files outside `root` are skipped, and any rule that raises degrades to a single `warn` finding rather than killing the run.
- Stage `op`: `"and"` (default) feeds previous candidates in; `"or"` runs the stage as a generator (candidates=None) and unions results by fingerprint.

`src/hoolint/strategies/base.py`:

```python
"""Shared per-file execution context passed to every stage."""
from dataclasses import dataclass, field
from pathlib import Path


@dataclass
class Context:
    path: Path
    root: Path
    mode: str            # "session" | "git"
    settings: dict
    rule_id: str
    severity: str
    notes: list[str] = field(default_factory=list)
    filter_skipped: bool = False
    _content: str | None = None

    def content(self) -> str:
        if self._content is None:
            self._content = self.path.read_text(errors="replace")
        return self._content

    def warn(self, msg: str) -> None:
        if msg not in self.notes:
            self.notes.append(msg)

    def skip_filter(self, msg: str) -> None:
        """A filter stage could not run: note it and disarm blocking.

        A skipped filter removed no false positives, so its survivors have not
        earned a block. Findings from this run degrade to warn.
        """
```

```python
"""Regex strategy: generate findings from matches, or filter candidates.

Uses google-re2, not stdlib `re`: patterns come from project config, and RE2's
linear-time guarantee means no pattern can hang the check. No lookaround.
"""
import re2
from hoolint.findings import Finding
from hoolint.strategies.base import Context


class RegexStrategy:
    def run(self, candidates: list[Finding] | None, stage: dict,
            ctx: Context) -> list[Finding]:
        pat = re2.compile(stage["pattern"])
        excludes = [re2.compile(p) for p in stage.get("exclude", [])]
        if candidates is not None:
            return [c for c in candidates if pat.search(c.span_text)
                    and not any(x.search(c.span_text) for x in excludes)]
        text = ctx.content()
        out = []
        for m in pat.finditer(text):
            span = m.group()
            if any(x.search(span) for x in excludes):
                continue
            start = text.count("\n", 0, m.start()) + 1
            end = start + span.rstrip("\n").count("\n")
            out.append(Finding(
                rule_id=ctx.rule_id, file=str(ctx.path.relative_to(ctx.root)),
                start_line=start, end_line=end, span_text=span,
                message=stage.get("message", f"matched {stage['pattern']}"),
                severity=ctx.severity))
        return out
```

```python
"""Run rules over files: stages sequence cheap-to-expensive per file."""
from concurrent.futures import ThreadPoolExecutor
from pathlib import Path
from hoolint.config import Config
from hoolint.findings import Finding
from hoolint.strategies import STRATEGIES
from hoolint.strategies.base import Context


def _run_rule(rule: dict, files: list[Path], root: Path, mode: str,
              settings: dict) -> list[Finding]:
    matched = [f for f in files
               if f.is_relative_to(root)
               and any(f.relative_to(root).full_match(g) for g in rule["globs"])]
    out: list[Finding] = []
    for path in matched:
        ctx = Context(path=path, root=root, mode=mode, settings=settings,
                      rule_id=rule["id"], severity=rule.get("severity", "warn"))
        cands: list[Finding] | None = None
        for stage in rule.get("stage", []):
            strat = STRATEGIES[stage["strategy"]]
            if cands is not None and stage.get("op") == "or":
                fresh = strat.run(None, stage, ctx)
                merged = {c.fingerprint: c for c in [*cands, *fresh]}
                cands = list(merged.values())
            else:
                cands = strat.run(cands, stage, ctx)
        for c in cands or []:
            c.notes.extend(n for n in ctx.notes if n not in c.notes)
            if ctx.filter_skipped and c.severity == "block":
                c.severity = "warn"
        out.extend(cands or [])
    return out


def _guarded(rule: dict, files: list[Path], root: Path, mode: str,
             settings: dict) -> list[Finding]:
    """One bad rule degrades to a note; it never kills the whole check."""
    try:
        return _run_rule(rule, files, root, mode, settings)
    except Exception as exc:                     # noqa: BLE001 - deliberate
        return [Finding(rule_id=rule["id"], file="", start_line=0, end_line=0,
                        span_text="", severity="warn",
                        message=f"rule failed, skipped: {exc!r}")]


def run(cfg: Config, files: list[Path], root: Path, mode: str) -> list[Finding]:
    """Execute all rules; rules run in parallel, stages sequentially."""
    # ponytail: thread pool; process pool only if CPU-bound rules dominate
    with ThreadPoolExecutor(max_workers=4) as ex:
        futures = [ex.submit(_guarded, r, files, root, mode, cfg.settings)
                   for r in cfg.rules]
        return [f for fut in futures for f in fut.result()]
```

```python
"""Committed team waivers; git review is the approval gate.

Entries carry the excused span so a reviewer can judge the waiver from the
diff alone, without checking out the branch and recomputing a hash.
"""
import tomllib
from pathlib import Path

import tomli_w

from hoolint.findings import Finding

FILE = "hoolint-waivers.toml"


def load(root: Path) -> set[str]:
    p = root / FILE
    if not p.exists():
        return set()
    data = tomllib.loads(p.read_text())
    return {w["fingerprint"] for w in data.get("waiver", [])}


def _excerpt(span: str) -> str:
    return "\n".join(span.splitlines()[:3])[:200]


def add(root: Path, finding: Finding, reason: str) -> None:
    """Append a reviewable waiver. Reason is mandatory — it lands in the diff."""
    if not reason.strip():
        raise ValueError("waiver reason is mandatory")
    p = root / FILE
    data = tomllib.loads(p.read_text()) if p.exists() else {}
    entries = data.get("waiver", [])
    entries.append({
        "fingerprint": finding.fingerprint,
        "rule_id": finding.rule_id,
        "file": finding.file,
        "lines": f"{finding.start_line}-{finding.end_line}",
        "span": _excerpt(finding.span_text),
        "reason": reason,
    })
    p.write_text(tomli_w.dumps({"waiver": entries}))


def prune(root: Path, live_fingerprints: set[str]) -> int:
    """Drop waivers whose span changed, so the file holds only live policy."""
    p = root / FILE
    if not p.exists():
        return 0
    entries = tomllib.loads(p.read_text()).get("waiver", [])
    kept = [w for w in entries if w["fingerprint"] in live_fingerprints]
    p.write_text(tomli_w.dumps({"waiver": kept}))
    return len(entries) - len(kept)
```

`src/hoolint/state.py`:

```python
"""Cross-stop state: stand-down counters, blocked files, waivable fingerprints.

Two counters, two loop shapes: `same_set` catches "same problem, no progress";
`consecutive` bounds a model that keeps editing the span without fixing it,
which changes the fingerprints and would otherwise reset `same_set` forever.
"""
import json
from pathlib import Path


def _path(root: Path) -> Path:
    return root / ".hoolint" / "state.json"


def _read(root: Path) -> dict:
    p = _path(root)
    return json.loads(p.read_text()) if p.exists() else {}


def bump(root: Path, records: list[dict],
         blocked_files: list[str]) -> tuple[int, int]:
    """Record a blocked stop. Returns (same_set_count, consecutive_count).

    Args:
        records: `Finding.record()` dicts for the blocking findings.
        blocked_files: paths that must stay in scope at the next stop.
    """
    p = _path(root)
    p.parent.mkdir(exist_ok=True)
    fps = sorted(r["fingerprint"] for r in records)
    prev = _read(root)
    same = prev.get("fingerprints") == fps and prev.get("same_set", 0) + 1 or 1
    consecutive = prev.get("consecutive", 0) + 1
    p.write_text(json.dumps({"fingerprints": fps, "same_set": same,
                             "consecutive": consecutive,
                             "blocked_files": blocked_files,
                             "last_findings": records}))
    return same, consecutive


def blocked_files(root: Path) -> list[Path]:
    """Files that still carried block findings at the previous stop."""
    return [Path(f) for f in _read(root).get("blocked_files", [])]


def last_fingerprints(root: Path) -> set[str]:
    """The only fingerprints `hoolint waive` will accept."""
    return {r["fingerprint"] for r in _read(root).get("last_findings", [])}


def finding_record(root: Path, fingerprint: str) -> dict | None:
    """The stored record for a surfaced finding, so waive can write its span."""
    for r in _read(root).get("last_findings", []):
        if r["fingerprint"] == fingerprint:
            return r
    return None


def record_findings(root: Path, records: list[dict]) -> None:
    """Remember a clean or warn-only run's findings so they stay waivable."""
    p = _path(root)
    p.parent.mkdir(exist_ok=True)
    p.write_text(json.dumps({"fingerprints": [], "same_set": 0,
                             "consecutive": 0, "blocked_files": [],
                             "last_findings": records}))


def reset(root: Path) -> None:
    _path(root).unlink(missing_ok=True)
```

```python
"""hoolint CLI: check, waive (trust and warmup added by later tasks)."""
import argparse
import json
import sys
from pathlib import Path

from hoolint import changes, journal, state, waivers   # trust added in Task 11
from hoolint.config import load_config
from hoolint.engine import run as engine_run
from hoolint.findings import Finding

WAIVE_HINT = (
    'Fix each finding. Only if the user explicitly sanctioned this code may you '
    'dismiss it: hoolint waive <fingerprint> --reason "user asked for X on <date/turn>". '
    'The reason must record that sanction — waivers are committed team policy, not '
    'your opinion about the rule.')


def _format(f: Finding) -> str:
    line = f"[{f.fingerprint}] {f.file}:{f.start_line}-{f.end_line} {f.rule_id}: {f.message}"
    if f.needs_judgment:
        line += f"\n  judge: {f.judgment_prompt}"
    for n in f.notes:
        line += f"\n  note: {n}"
    return line


def _system_message(text: str) -> None:
    """Stop-hook stdout is discarded unless it is a structured response."""
    print(json.dumps({"systemMessage": text}))


def _cmd_check(args: argparse.Namespace) -> int:
    root = Path(args.root).resolve()
    cfg = load_config(root)
    session_id, stop_hook_active = "default", False
    if args.mode == "session":
        hook = json.load(sys.stdin) if not sys.stdin.isatty() else {}
        session_id = hook.get("session_id", "default")
        stop_hook_active = bool(hook.get("stop_hook_active"))
        # Files still blocked last run stay in scope even if nothing was edited.
        seen = {p: None for p in journal.files(root, session_id)}
        seen.update({p: None for p in state.blocked_files(root) if p.exists()})
        files = list(seen)
    else:
        ref = args.ref or cfg.settings.get("git_ref", "auto")
        files = changes.git_changed(root, ref)
    found = engine_run(cfg, files, root, args.mode)
    waived = waivers.load(root)
    found = [f for f in found if f.fingerprint not in waived]
    blocks = [f for f in found if f.severity == "block"]
    warns = [f for f in found if f.severity == "warn"]

    if args.mode == "git":
        for f in found:
            print(_format(f))
        return 1 if blocks else 0

    if not blocks:
        journal.clear(root, session_id)
        state.record_findings(root, [f.record() for f in found])
        if warns:
            _system_message("hoolint:\n" + "\n".join(_format(f) for f in warns))
        return 0

    same, consecutive = state.bump(root, [f.record() for f in blocks],
                                   [str(root / f.file) for f in blocks])
    limit = cfg.settings.get("stand_down_after", 2)
    if same >= limit or consecutive >= limit or (stop_hook_active
                                                 and consecutive >= limit):
        state.record_findings(root, [f.record() for f in found])
        journal.clear(root, session_id)
        report = "\n".join(_format(f) for f in blocks)
        _system_message(
            f"hoolint stood down after {consecutive} consecutive blocked stops "
            f"— these need a human decision:\n{report}")
        return 0
    print(f"hoolint: {len(blocks)} blocking finding(s).", file=sys.stderr)
    for f in blocks:
        print(_format(f), file=sys.stderr)
    print(WAIVE_HINT, file=sys.stderr)
    return 2


def _cmd_waive(args: argparse.Namespace) -> int:
    root = Path(args.root).resolve()
    if args.prune:
        cfg = load_config(root)
        live = engine_run(cfg, changes.git_changed(root, "HEAD"), root, "git")
        dropped = waivers.prune(root, {f.fingerprint for f in live})
        print(f"pruned {dropped} waiver(s) whose span no longer matches")
        return 0
    record = state.finding_record(root, args.fingerprint)
    if record is None:
        print(f"refusing: {args.fingerprint} was not reported by the last check. "
              "Waivers are only for findings hoolint actually surfaced.",
              file=sys.stderr)
        return 1
    waivers.add(root, Finding.from_record(record), args.reason)
    print(f"waived {args.fingerprint} (review lands in the PR diff)")
    return 0


def main(argv: list[str] | None = None) -> int:
    p = argparse.ArgumentParser(prog="hoolint")
    sub = p.add_subparsers(dest="cmd", required=True)
    c = sub.add_parser("check")
    c.add_argument("--mode", choices=["session", "git"], default="session")
    c.add_argument("--ref", default=None)   # None -> settings["git_ref"]
    c.add_argument("--root", default=".")
    c.set_defaults(fn=_cmd_check)
    w = sub.add_parser("waive")
    w.add_argument("fingerprint", nargs="?")
    w.add_argument("--reason")
    w.add_argument("--prune", action="store_true")
    w.add_argument("--root", default=".")
    w.set_defaults(fn=_cmd_waive)
    args = p.parse_args(argv)
    return args.fn(args)


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Redundancy-with-code scoring via model2vec static embeddings.

Heuristic shortlist filter: a comment highly similar to its adjacent code
restates it. The escalate stage remains the judge.
"""
import os
import re
from pathlib import Path

import numpy as np

from hoolint.findings import Finding
from hoolint.strategies.base import Context

DEFAULT_MODEL = "minishlab/potion-base-8M"
_COMMENT = re.compile(r"^\s*#")


def marker_path() -> Path:
    """Ready-marker location; env-overridable so tests can isolate it."""
    base = os.environ.get("HOOLINT_CACHE_DIR")
    return (Path(base) if base else Path.home() / ".cache" / "hoolint") / "model-ready"


def model_ready() -> bool:
    return marker_path().exists()


def download_model(name: str = DEFAULT_MODEL) -> None:
    """Warmup path: downloads, then writes the ready marker."""
    from model2vec import StaticModel
    StaticModel.from_pretrained(name)
    marker = marker_path()
    marker.parent.mkdir(parents=True, exist_ok=True)
    marker.touch()


def _adjacent_code(text: str, start_line: int, end_line: int, n: int = 20) -> str:
    """Code the comment is attached to: after it, or before it if nothing follows.

    A trailing comment block (file footer, end of a function) has no code after
    it; judging it against the code above is what a reader actually does.
    """
    lines = text.splitlines()
    after = [ln for ln in lines[end_line:] if ln.strip() and not _COMMENT.match(ln)]
    if after:
        return "\n".join(after[:n])
    before = [ln for ln in lines[:max(start_line - 1, 0)]
              if ln.strip() and not _COMMENT.match(ln)]
    return "\n".join(before[-n:])


class SemanticStrategy:
    def __init__(self, encoder=None):
        self._encoder = encoder

    def _get_encoder(self, model_name: str):
        if self._encoder is None:
            os.environ["HF_HUB_OFFLINE"] = "1"  # never download at check time
            from model2vec import StaticModel
            self._encoder = StaticModel.from_pretrained(model_name)
        return self._encoder

    def run(self, candidates: list[Finding] | None, stage: dict,
            ctx: Context) -> list[Finding]:
        if candidates is None:
            return []          # semantic never generates, only filters
        if self._encoder is None and not model_ready():
            ctx.skip_filter("semantic skipped (warming up); run `hoolint warmup`")
            return candidates
        enc = self._get_encoder(
            ctx.settings.get("semantic_model", DEFAULT_MODEL))
        threshold = stage.get("threshold", 0.6)
        kept = []
        for c in candidates:
            code = _adjacent_code(ctx.content(), c.start_line, c.end_line)
            if not code:
                kept.append(c)
                continue
            v = enc.encode([c.span_text.strip(), code])
            sim = float(v[0] @ v[1] /
                        (np.linalg.norm(v[0]) * np.linalg.norm(v[1]) + 1e-9))
            if sim >= threshold:
                c.notes.append(f"semantic: redundancy {sim:.2f} >= {threshold}")
                kept.append(c)
        return kept
```

```python
# tests/test_semantic_calibration.py
import json
from pathlib import Path

import pytest

from hoolint.strategies.semantic import DEFAULT_MODEL

FIXTURES = Path(__file__).parent / "fixtures" / "comment_pairs.jsonl"


@pytest.mark.slow
def test_threshold_separates_labelled_pairs():
    """Records the real model's separation; fails if a model swap degrades it."""
    from model2vec import StaticModel
    import numpy as np
    enc = StaticModel.from_pretrained(DEFAULT_MODEL)
    pairs = [json.loads(ln) for ln in FIXTURES.read_text().splitlines()]
    scores = {True: [], False: []}
    for p in pairs:
        v = enc.encode([p["comment"], p["code"]])
        sim = float(v[0] @ v[1] /
                    (np.linalg.norm(v[0]) * np.linalg.norm(v[1]) + 1e-9))
        scores[p["redundant"]].append(sim)
    threshold = (max(scores[False]) + min(scores[True])) / 2
    fp = sum(s >= threshold for s in scores[False]) / len(scores[False])
    print(f"separation: redundant>={min(scores[True]):.3f} "
          f"useful<={max(scores[False]):.3f} threshold={threshold:.3f} fp={fp:.2f}")
    assert fp <= 0.2, "threshold cannot separate redundant from useful comments"
```

```python
"""Judge candidates via a local OpenAI-compatible endpoint (Ollama, vLLM...).

Never a cloud provider. That is enforced, not assumed: project config supplies
base_url, so an unvalidated host would let any repo exfiltrate file content on
the next Stop hook.
"""
import ipaddress
import os
import socket
import time
from urllib.parse import urlparse

import httpx

from hoolint.findings import Finding
from hoolint.strategies.base import Context

DEFAULT_BASE = "http://localhost:11434/v1"


def is_local(base_url: str) -> bool:
    """True iff the resolved host is loopback, private, or link-local."""
    host = urlparse(base_url).hostname
    if not host:
        return False
    try:
        infos = socket.getaddrinfo(host, None)
    except socket.gaierror:
        return False
    for info in infos:
        ip = ipaddress.ip_address(info[4][0])
        if not (ip.is_loopback or ip.is_private or ip.is_link_local):
            return False
    return bool(infos)


class LocalLLMStrategy:
    def __init__(self, transport: httpx.BaseTransport | None = None):
        self._transport = transport

    def run(self, candidates: list[Finding] | None, stage: dict,
            ctx: Context) -> list[Finding]:
        if not candidates:
            return []
        base = os.environ.get("HOOLINT_LLM_BASE_URL") or stage.get(
            "base_url", DEFAULT_BASE)
        if not is_local(base):
            ctx.skip_filter(f"local_llm refused non-local endpoint: {base}")
            return candidates
        cap = stage.get("max_candidates", 10)
        if len(candidates) > cap:
            ctx.skip_filter(f"local_llm budget exhausted (>{cap} candidates)")
            return candidates
        deadline = time.monotonic() + stage.get("budget_seconds", 60)
        client = httpx.Client(base_url=base, transport=self._transport,
                              timeout=stage.get("timeout", 30))
        try:
            if time.monotonic() > deadline:
                ctx.skip_filter("local_llm budget exhausted")
                return candidates
            # One request per file, not per candidate: wall time stays bounded.
            numbered = "\n\n".join(
                f"[{i}]\n{c.span_text}" for i, c in enumerate(candidates))
            prompt = stage["prompt"].format(span=numbered, code=ctx.content())
            r = client.post("/chat/completions", json={
                "model": stage["model"],
                "messages": [{"role": "user", "content": prompt}],
                "temperature": 0,
            })
            r.raise_for_status()
            reply = r.json()["choices"][0]["message"]["content"]
            verdicts = {}
            for line in reply.splitlines():
                if line.strip().startswith("["):
                    idx, _, rest = line.partition("]")
                    verdicts[idx.strip("[ ")] = rest.strip()
            kept = []
            for i, c in enumerate(candidates):
                verdict = verdicts.get(str(i), "")
                if "VIOLATION" in verdict.upper():
                    c.notes.append(f"local_llm: {verdict[:120]}")
                    kept.append(c)
            return kept
        except httpx.HTTPStatusError as exc:
            body = exc.response.text[:200]
            ctx.skip_filter(
                f"local_llm skipped (HTTP {exc.response.status_code} "
                f"from {base}: {body})")
            return candidates
        except httpx.HTTPError:
            ctx.skip_filter(f"local_llm skipped (endpoint unreachable: {base})")
            return candidates
        finally:
            client.close()
```

```python
"""Hand the shortlist to the session model for judgment (never an API call)."""
from hoolint.findings import Finding
from hoolint.strategies.base import Context


class EscalateStrategy:
    def run(self, candidates: list[Finding] | None, stage: dict,
            ctx: Context) -> list[Finding]:
        if not candidates:
            return []
        for c in candidates:
            if ctx.mode == "git":
                # Severity is retained: CI must still fail on unjudged blocks.
                c.notes.append("not-judged (no session)")
            else:
                c.needs_judgment = True
                c.judgment_prompt = stage.get("prompt", "")
        return candidates
```

```python
_LINK = re.compile(r"\[[^\]]*\]\(([^)]+)\)")
_REF = re.compile(r"`([\w./-]+\.(?:py|md|toml|json|sh|js|ts|yaml|yml))`")


def _finding(ctx: Context, line: int, span: str, message: str) -> Finding:
    return Finding(rule_id=ctx.rule_id,
                   file=str(ctx.path.relative_to(ctx.root)),
                   start_line=line, end_line=line, span_text=span,
                   message=message, severity=ctx.severity)


class DocLinksStrategy:
    def run(self, candidates, stage, ctx: Context) -> list[Finding]:
        out = []
        for i, ln in enumerate(ctx.content().splitlines(), 1):
            for m in _LINK.finditer(ln):
                target = m.group(1).split("#")[0].strip()
                if not target or "://" in target or target.startswith("mailto:"):
                    continue
                if not (ctx.path.parent / target).exists():
                    out.append(_finding(ctx, i, target,
                                        f"broken relative link: {target}"))
        return out


class DocRefsStrategy:
    def run(self, candidates, stage, ctx: Context) -> list[Finding]:
        out = []
        for i, ln in enumerate(ctx.content().splitlines(), 1):
            for m in _REF.finditer(ln):
                ref = m.group(1)
                if not (ctx.root / ref).exists() and not (ctx.path.parent / ref).exists():
                    out.append(_finding(ctx, i, ref,
                                        f"references missing file: {ref}"))
        return out
```

```python
"""Opt-in gate for custom Python rules: no drive-by code execution.

Trust binds to the content of hoolint_rules/, not to the directory. A grant is
consent to run code the user reviewed, not to run whatever later lands there.
"""
import hashlib
import os
import tomllib
from pathlib import Path

import tomli_w


def _config_file() -> Path:
    base = Path(os.environ.get("XDG_CONFIG_HOME", Path.home() / ".config"))
    return base / "hoolint" / "trusted.toml"


def rules_digest(root: Path) -> str:
    """Digest over every rule file's name and bytes."""
    rules_dir = root / "hoolint_rules"
    h = hashlib.sha256()
    for py in sorted(rules_dir.glob("*.py")) if rules_dir.is_dir() else []:
        h.update(py.name.encode())
        h.update(py.read_bytes())
    return h.hexdigest()


def is_trusted(root: Path) -> bool:
    f = _config_file()
    if not f.exists():
        return False
    granted = tomllib.loads(f.read_text()).get("projects", {})
    return granted.get(str(root.resolve())) == rules_digest(root)


def grant(root: Path) -> None:
    f = _config_file()
    f.parent.mkdir(parents=True, exist_ok=True)
    data = tomllib.loads(f.read_text()) if f.exists() else {}
    projects = data.get("projects", {})
    projects[str(root.resolve())] = rules_digest(root)
    f.write_text(tomli_w.dumps({"projects": projects}))


def load_custom_rules(root: Path) -> tuple[list[dict], str | None]:
    """Load hoolint_rules/*.py if the project is trusted.

    Returns:
        (rules, notice): notice is a user-facing string when rules were
        present but skipped, else None.
    """
    rules_dir = root / "hoolint_rules"
    if not rules_dir.is_dir():
        return [], None
    if not is_trusted(root):
        return [], "custom rules present, not loaded — run `hoolint trust`"
    rules = []
    for py in sorted(rules_dir.glob("*.py")):
        ns: dict = {}
        exec(compile(py.read_text(), str(py), "exec"), ns)  # trusted by user
        if isinstance(ns.get("rule"), dict):
            rules.append(ns["rule"])
    return rules, None
```

```python
"""PostToolUse: append the edited file to the session journal. Stdlib only."""
import json
import os
import sys


def main() -> int:
    try:
        event = json.load(sys.stdin)
    except json.JSONDecodeError:
        return 0
    file_path = (event.get("tool_input") or {}).get("file_path")
    if not file_path:
        return 0
    root = os.environ.get("CLAUDE_PROJECT_DIR", os.getcwd())

    hoolint_dir = os.path.join(root, ".hoolint")

            f.write("*\n")
    with open(os.path.join(hoolint_dir, f"session-{session}.jsonl"), "a") as f:
        f.write(json.dumps({"file": file_path}) + "\n")
    return 0


if __name__ == "__main__":
```

```markdown
# hoolint

Claude Code plugin: when the model stops, hoolint checks every file it
touched — code and docs — through stacked strategies of increasing cost,
and blocks the stop until findings are fixed or waived.

Name: **hoolint** = hook + lint.

## How it works

1. `PostToolUse` journals every file Claude writes or edits.
2. `Stop` runs `hoolint check`: rules pipe candidates through stages —
   `regex` (cheap filter) → `semantic` (model2vec redundancy-with-code) →
   `local_llm` (Ollama/vLLM/LM Studio via one OpenAI-compatible endpoint) →
   `escalate` (the session model judges the shortlist).
3. Confirmed `block` findings exit 2: Claude keeps working and fixes them.
   After `stand_down_after` (default 2) blocked stops, hoolint stands down and
   hands the findings to the human. A filter tier that could not run (no model,
   no endpoint) demotes that rule to advisory for the run — an
   incompletely-configured install reports but never blocks.

## Waivers

`hoolint waive <fingerprint> --reason "<why>"` writes to
`hoolint-waivers.toml` — committed, team-shared, reviewed in the PR diff. Each
entry carries the excused span and its location, so a reviewer can judge it
without checking out the branch. A waiver stops matching once the excused span
changes; `hoolint waive --prune` drops entries that no longer match. Waiving is
only possible for a finding hoolint actually reported, and is reserved for code
the user explicitly sanctioned.

## CI / verification pipelines

`uv run --project <plugin>/app hoolint check --mode git --ref <ref>` checks
`git diff` instead of the session journal; exit 1 on block findings.
`escalate` stages mark findings `not-judged` but keep their severity, so CI
still fails on them; `local_llm` runs whenever a local endpoint is up.

## Configuration

`hoolint.toml` at the project root. Stock rules (`verbose-comments`,
`doc-broken-links`, `doc-drift`) are on by default; same-id rules override
wholesale, `enabled = false` disables. Custom Python rules in `hoolint_rules/`
load only after `hoolint trust`, and the grant is pinned to those files'
content — adding or editing a rule re-arms the prompt.

`local_llm.base_url` is restricted to loopback and private addresses, so a
project's config cannot ship your code to a public host.

See `CONTEXT.md` for the vocabulary.
```
